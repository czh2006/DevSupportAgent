# DevSupport Agent

开发者故障排查与工单协作平台。

## 当前进度

- 创建 FastAPI 后端
- 提供健康检查接口
- 使用 SQLite 持久化排障会话
- 支持创建和查询排障会话
- 校验请求参数，查询不存在的会话返回 404
- 支持添加和分页查询会话消息
- 消息按会话隔离，重启后仍然保留
- 用户消息角色由后端指定
- 引入服务层管理排障会话业务规则
- 支持将会话从 created 受控地流转到 investigating
- 拒绝重复开始排查和不存在会话的状态变更
- 支持按会话保存 API 版本、运行环境、请求编号和 HTTP 状态码
- 支持分多轮补充排障上下文，不会覆盖已保存字段
- 已解决或转人工的会话不能继续修改排障上下文
- 支持通过环境变量启用或关闭 LLM 能力
- 启用 LLM 时校验 API Key、模型接口地址和模型名称，避免错误配置运行
- 模型密钥使用本地 `.env` 管理，不提交 Git
- 新增 LLM 结构化上下文提取器，可处理口语化环境与故障描述
- 模型输出必须包含用户原文依据，并经过服务端校验
- 证据缺失或不属于原始消息的模型结果会被拒绝，避免幻觉污染排障上下文
- 当前 LLM 提取器使用假模型测试，尚未默认接入线上请求链路
- 对模型提取结果增加字段值与原文证据的一致性校验
- 拒绝状态码、版本、请求编号不一致及空白证据
- 使用对抗测试验证真实原文证据不能被用于支持错误字段

## 启动后端

在项目根目录激活虚拟环境：

```powershell
.\.venv\Scripts\Activate.ps1
```

然后启动服务：

```powershell
cd backend
python -m uvicorn app.main:app --reload
```

健康检查：http://127.0.0.1:8000/health

接口文档：http://127.0.0.1:8000/docs

## 运行测试

进入后端目录后执行：

```powershell
python -m pytest -v
```

测试使用独立的内存 SQLite 数据库，不会修改本地运行数据。
